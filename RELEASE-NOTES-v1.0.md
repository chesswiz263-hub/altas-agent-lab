# ATLAS v1.0.0 — Evidence-first research foundations

Single cumulative upgrade incorporating v0.7 (relevance/abstention), v0.8 (provenance), v0.9 (research dossiers and bounded arithmetic), and v1.0 (API integration and evaluations).

Public demo now explains why evidence was accepted or rejected, exports a JSON evidence dossier, and abstains on the two quantum-physics queries which exposed spurious lexical matches in v0.6. Private Python application exposes `POST /api/research/dossier` with citation IDs, passage digests, conservative hypothesis statuses and exact rational arithmetic checks.

**No autonomous dark-matter report generation, live scientific search, semantic entailment proof, or independently verified scientific citations.** The public demo remains a static, deterministic research walkthrough.

See `docs/RESEARCH_INTEGRITY.md` for exact guarantees and remaining work.
